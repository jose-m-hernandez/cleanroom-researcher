# Recipe scaler

A small shell tool that scales the ingredient amounts of a recipe to a new
number of servings and prints the result.

## Layout

- `scale.sh` is the entry script: recipe file in, scaled recipe out.
- `check.sh` scales the pancake recipe and diffs the result.
- `recipes/pancakes.txt` and `recipes/dal.txt` are the two example recipes.
- `recipes/expected-pancakes-x2.txt` is the pancake recipe at double servings.
- `README.md` explains the recipe file format for the kitchen team.

## Commands

- `sh scale.sh recipes/pancakes.txt 8` prints the pancake recipe for eight servings.
- `sh check.sh` runs the comparison against the expected file.
- `ls recipes/` lists the recipes that are available.

## Conventions

- A recipe file has a comment line first, then one ingredient per line.
- An ingredient line is an amount, a unit, and a name, split by single spaces.
- Units are g, ml, or pcs. Do not add other units without asking.
- The script is POSIX shell plus awk and needs nothing else installed.
- Keep awk programs short; comment each block with what it computes.
- Errors go to standard error and the script exits with status 2.

## Working style

- Explain a change in two sentences before editing.
- Re-run `sh check.sh` after every edit to the script.
- Leave the example recipes alone unless asked.

## Patterns
- Store amounts as whole grams or millilitres, never fractions; rounding cup fractions made totals drift.
- Do not scale pan size with servings; every recipe assumes one 24 cm pan.

## Decisions
- Counted items such as eggs round up to a whole piece when scaling.

## Warnings
- Scale salt and spices at seventy percent of the serving ratio, not linearly.

## Status
- The default serving count is six (it was four).
