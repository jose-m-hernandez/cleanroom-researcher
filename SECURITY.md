# Security

## Reporting a vulnerability

Report a vulnerability in this repository privately: open this repository's Security tab, choose "Report a vulnerability", and describe what you found, how to reproduce it, and what it affects. Only the maintainers and you can see the report. Please do not open a public issue or pull request about it.

## What belongs here

A flaw in the scripts, checks or workflows in this repository belongs here. A flaw in a third-party AI tool that an experiment studies belongs with that tool's vendor; report it to them, not here.
