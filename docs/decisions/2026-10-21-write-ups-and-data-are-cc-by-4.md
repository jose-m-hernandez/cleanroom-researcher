# Write-ups and recorded data are licensed CC-BY-4.0; code stays MIT

Date: 2026-10-21

> **The rule.** Code (`tools/`, `tests/`, and each experiment's `harness/`) is licensed MIT, in `LICENSE`. Write-ups, syntheses, protocols and recorded data are licensed CC-BY-4.0, in a second licence file with a line stating its scope. Material under `recorded/` that comes from a target keeps its own licence, which its source record names.

## Why

People who repeat or build on an experiment need to know what they may reuse and how to credit it. MIT suits code. A write-up or a dataset is cited and adapted the way a paper is, and CC-BY-4.0 is the licence scientific publishing uses for that: reuse for any purpose, with attribution.

The licence of a target's own material is set by its authors, not by us, so this repository never relicenses it.
